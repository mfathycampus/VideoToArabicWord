# محوّل الفيديو إلى مستند Word عربي

تطبيق سطح مكتب **محلي بالكامل** يحوّل فيديو تعليميًا إلى مستند Word عربي
منظّم: تفريغ صوتي + صور المشاهد مرتّبة زمنيًا.

```
Video → Metadata → Audio → Transcription → Scenes → Keyframes → Matching → DOCX
```

لا يُرفع أي ملف إلى الإنترنت. الاتصال الوحيد هو تنزيل نموذج التفريغ مرة
واحدة، بإذن صريح منك، وبعدها يعمل التطبيق دون اتصال.

---

## التشغيل السريع

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows   —   source .venv/bin/activate على غيره
python -m pip install -r requirements.txt
python tools/doctor.py            # يتحقق من البيئة قبل التشغيل
python app.py
```

> **مهم:** الحزمة المطلوبة اسمها **`python-docx`** وليس `docx`. حزمة
> `docx` مشروع مهجور من زمن Python 2 ويسبب خطأ
> `No module named 'exceptions'` الغامض. التفاصيل والإصلاح في
> [`INSTALL.md`](INSTALL.md).

للتشغيل من سطر الأوامر دون واجهة:

```bash
python -m tools.run_pipeline --video "محاضرة.mp4" --output ~/VideoToDocOutput
```

| المكوّن | ملاحظة |
|---|---|
| Python 3.10+ | |

## قرارات معمارية جوهرية

**ADR-010 · المستند مدفوع بالنص لا بالصور.** كل مقطع منطوق يظهر **مرة
واحدة بالضبط**، والصور تُحقن عند طوابعها الزمنية. الضمانة مفروضة برمجيًا
في `TimelineMatcher.assert_lossless` وتُفحص في كل مستند ناتج.

**ADR-011 · عتبات كشف المشاهد تكيّفية.** لا رقم مطلق في الكود. العتبة
تُشتق من توزيع درجات كل فيديو (`median + k·MAD`) مع حدّ أدنى. عايِر على
مادتك بـ `tools/calibrate_scenes.py`.

**ADR-012 · بلا PyTorch.** `faster-whisper` يعمل على CTranslate2. اكتشاف
CUDA وأنواع الحساب عبر `ctranslate2` مباشرة — يوفّر ~2.5GB ويزيل أكبر
مصدر لمشاكل التغليف.

**ADR-013 · ffmpeg و ffprobe مشحونان.** `imageio-ffmpeg` لا يشحن ffprobe
إطلاقًا؛ الاعتماد عليه يُفشل قراءة الميتاداتا من أول دالة.

**ADR-014 · لا تنزيل تلقائي للنموذج.** الاتصال الشبكي الوحيد يشترط إذنًا
صريحًا من المستخدم مرة واحدة.

**ADR-015 · الدوران يُستنتج وقت التشغيل.** بعض بُنى OpenCV تطبّق مصفوفة
عرض الحاوية وبعضها يتجاهلها. افتراض أيّهما ينتج صورًا مقلوبة على نصف
الأجهزة، والـ XML يبقى سليمًا فلا يكشف العطل. القرار يُتَّخذ بمقارنة
الإطار بمرجع من FFmpeg (`utils/frames.resolve_rotation_plan`).

## الاستئناف

كل مرحلة تحفظ ناتجها بـ checksum في مجلد المهمة. إعادة التشغيل تتخطى
المراحل التي ما زال ناتجها صالحًا. حذف ناتج أو العبث به يُبطله ويُبطل كل
ما يليه تلقائيًا.

```
<output>/<اسم الفيديو>/
├── job_state.json      الحالة والمراحل المكتملة والـ checksums
├── metadata.json       عقد VideoMetadata
├── transcription.json  عقد TranscriptionResult
├── scenes.json         المشاهد ودرجات التغيّر
├── keyframes.json      الصور وبياناتها
├── matches.json        عناصر المستند + ثوابت سلامة النص
├── keyframes/          الصور المستخرجة
└── <اسم الفيديو>.docx  المخرج النهائي
```

```bash
python tools/measure_wer.py --eval-set my_eval.json --model large-v3
```

حيث `my_eval.json` قائمة من `{"file": "...wav", "norm": "النص الصحيح"}`.
تُبلَّغ ثلاثة مقاييس معًا: WER الصارم، WER المتسامح إملائيًا، و CER.

## اختيار النموذج — أرقام مقاسة

قياس فعلي على FLEURS العربية (لهجة مصرية)، 86 ثانية كلام بشري بنصوص
مرجعية، على معالج بنواتين بصيغة `int8`:

| النموذج | دقة الكلمات | دقة الحروف | معامل الزمن | الحجم |
|---|---|---|---|---|
| **large-v3-turbo** (افتراضي) | **92.54%** | **98.64%** | **1.28×** | 1.7GB |
| large-v3 | 90.30% | 98.18% | 3.33× | 3.1GB |
| medium | 87.31% | 97.43% | 2.78× | 1.5GB |

النتيجة كانت مفاجئة: **turbo تفوّق على large-v3 في الدقة والسرعة معًا**
على العربية، ولهذا هو الافتراضي. لا تغيّر الترتيب دون إعادة القياس بـ
`tools/measure_wer.py`.

### كم تستغرق المعالجة؟

معامل الزمن يضرب في مدة الفيديو. لمحاضرة ساعة وثلث (81 دقيقة):

| النموذج | على المعالج | على كرت شاشة NVIDIA |
|---|---|---|
| large-v3-turbo | ~1 ساعة و45 دقيقة | ~13 دقيقة |
| large-v3 | ~4 ساعات و30 دقيقة | ~33 دقيقة |

الواجهة تعرض هذا التقدير **قبل** الضغط على «ابدأ»، وشريط التقدّم يعرض
الوقت المتبقي أثناء العمل.

## جودة المخرج — ما تغيّر ولماذا

فحص مخرج حقيقي (تسجيل شاشة 88 ثانية لنظام ويب) كشف ثلاث مشكلات:

| القياس | قبل | بعد |
|---|---|---|
| عدد الصور | 13 (**3 فارغة**) | 6 كلها ذات محتوى |
| حجم المستند | **8.50 MB** | **0.62 MB** |
| عدد الصفحات | صفحة لكل صورة | شكلان في الصفحة |

**١ · شاشات التحميل.** كاشف المشاهد يُطلق عند لحظة التغيّر، وهي بالضبط
لحظة بدء تحميل الصفحة. الحل: المنتقي يجرّب خمس لحظات داخل كل مشهد ويختار
اللحظة **المستقرة** — يقارن الإطار بإطار بعده وبحالة المشهد الأخيرة، ويعاقب
غير المستقر. مقياس كثافة الحواف يرفض الفارغ (قِيس: الفارغ 1.0–1.3٪ مقابل
المفيد 2٪ فأعلى).

**٢ · التكرار.** بصمة إدراكية (dHash) تُقارَن بكل الصور المحفوظة لا
بالسابقة فقط، فلا تتسرّب لقطات شبه متطابقة.

**٣ · الحجم.** JPEG بجودة 82 وعرض 1366 بدل PNG بعرض كامل. محاضرة ساعة
كانت ستنتج مستندًا يتجاوز 300 ميجابايت يتعذّر فتحه.

## القالب الاحترافي

المستند يُبنى بأنماط Word حقيقية لا بتنسيق يدوي، فيعمل الفهرس التلقائي
وجزء التنقّل، ويمكن تغيير الهوية البصرية كلها من مكان واحد.

* **غلاف** بالعنوان وجدول حقائق المصدر
* **فهرس تلقائي** (F9 داخل Word لتحديثه)
* **أقسام** بعناوين، طولها مشتقّ من مدة الفيديو (3–12 قسمًا مهما كان الطول)
* **فقرات مدموجة** — مقاطع Whisper القصيرة تُجمّع في فقرات مقروءة
* **أشكال مرقّمة** بتسمية تحمل الرقم والتوقيت
* **رأس وتذييل** مع ترقيم «صفحة س من ص»

البنية والتصيير منفصلان: `document/planner.py` يقرر *ماذا* في الوثيقة،
و`document/template.py` يقرر *كيف* تبدو. استبدال أحدهما لا يمسّ الآخر.

## إعادة الصياغة بالذكاء الاصطناعي (اختيارية)

**معطّلة افتراضيًا** (ADR-016). مخرج Whisper كلام منطوق: جُمل ناقصة وتكرار
وحشو. إعادة الصياغة تحوّله إلى نثر مكتوب مع عناوين أقسام وملخّص تنفيذي.

| المزوّد | الخصوصية |
|---|---|
| **Claude API** (افتراضي) | ⚠ يُرسل نص التفريغ لخوادم Anthropic |
| **Ollama** (محلي) | النص لا يغادر جهازك إطلاقًا |
| خدمة أخرى بواجهة OpenAI | ⚠ يُرسل نص التفريغ لخادم خارجي |

```powershell
setx ANTHROPIC_API_KEY "sk-ant-..."     # ثم أعد فتح البرنامج
```

الإعداد الكامل في [`REWRITE_SETUP.md`](REWRITE_SETUP.md). الفيديو والصوت والصور **لا تُرسل أبدًا** —
النص فقط.

**الضمانات المفروضة برمجيًا:**

* النص الخام يبقى في `transcription.json` كما هو (ADR-005)
* كل قسم يحمل `segment_ids` مصدره — التتبّع ممكن دائمًا
* فشل الصياغة **لا يُفشل المهمة**: سقوط تلقائي إلى النص الخام
* فشل دفعة واحدة يستخدم نصها الخام بدل إسقاطها
* النموذج مُوجَّه صراحةً: لا يضيف معلومة ولا يحذف معنى

## الهوية البصرية

المستند يستخدم شعار المشروع من `assets/logo.png`، ويشتقّ لونه الأساسي
منه (`#2D2E82`). الشعار يظهر في الغلاف وفي رأس كل صفحة.

لتغييره: استبدل `assets/logo.png`، أو حدّد مسارًا آخر في الإعداد:

```yaml
document:
  logo_path: C:\path\to\logo.png
  logo_width_inches: 2.1
```

غياب الشعار لا يُفشل التوليد — يخرج المستند بدونه.

## ملاحظة مهمة: محارف الاتجاه في Word

النسخة السابقة كانت تستخدم محارف العزل الاتجاهي (U+2066/U+2069) لمنع
انعكاس الأرقام. **تعمل في LibreOffice وتفشل في Microsoft Word**: يعرضها
Word مربّعات ظاهرة مكتوبًا داخلها `LRI` و `PDI`.

الحل الحالي بنيوي بلا أي محرف مضاف:

* قيمة لاتينية/رقمية خالصة ⇒ **فقرة LTR** (`w:bidi val=0`) بالمحاذاة
  المطلوبة، فيصح ترتيبها الداخلي
* نص مختلط ⇒ يُقسَّم إلى `runs`: العربية بـ `w:rtl` واللاتينية بدونه
* التواريخ ⇒ صيغة عربية طبيعية (`31 أغسطس 2026`) بدل ISO، لأن مجموعات
  الأرقام المفصولة بشرطات تنعكس بصريًا مهما ضُبط الاتجاه

اختبار انحدار يفشل إن عاد أي محرف تحكّم اتجاهي إلى المستند.
