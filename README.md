# محوّل الفيديو إلى مستند Word عربي

تطبيق سطح مكتب **محلي افتراضيًّا** يحوّل فيديو تعليميًا إلى مستند Word عربي
منظّم: تفريغ صوتي + صور المشاهد مرتّبة زمنيًا.

```
Video → Metadata → Audio → Transcription → Scenes → Keyframes → Matching → DOCX
```

لا يُرفع أي ملف فيديو أو صوت إلى الإنترنت. التفريغ واللقطات وقراءة الشاشة
تجري على جهازك، والاتصال الوحيد في الإعداد الافتراضي هو تنزيل نموذج التفريغ
مرة واحدة بإذن صريح منك.

> **استثناء تختاره أنت:** إن فعّلت «إعادة الصياغة» أو «الحزمة التعليمية» أو
> «الترجمة» بمزوّد سحابي (Claude أو OpenAI-compatible)، يُرسَل **النص**
> المفرَّغ — ومعه نصّ الشاشة المقروء ما لم تعطّل `include_screen_text` — إلى
> ذلك المزوّد. كل إرسال فعلي يُسجَّل في `audit.jsonl` بجوار المستند
> (`text_left_device`). ومزوّد `ollama` يُبقي كل شيء على الجهاز.

**والمصدر قد يكون صوتًا خالصًا.** زر «اختيار ملف صوتي» يقبل أي امتداد
يفكّه ffmpeg (‏mp3، m4a، wav، flac، opus، wma…) وينتج المستند المنسّق
نفسه بلا لقطات: غلاف وفهرس وأقسام وفقرات مدموجة وترجمات SRT/VTT.

---

## التنزيل — للمعلّم

[**⬇ نزّل أحدث إصدار**](https://github.com/mfathycampus/VideoToArabicWord/releases/latest)

ملف واحد اسمه `VideoToArabicWord-*-setup.exe`. شغّله واتبع الخطوات —
لا يحتاج صلاحيات مدير، ولا Python، ولا أي تثبيت آخر.

> **تحذير ويندوز عند أول تشغيل.** المثبِّت غير موقَّع رقميًّا بعد، فتظهر
> شاشة SmartScreen زرقاء. اختر **مزيد من المعلومات ← تشغيل على أي حال**.

عند أول معالجة ينزّل البرنامج نموذج التفريغ مرّة واحدة (≈1.7GB) بعد أن
يستأذنك. بعدها يعمل دون اتصال نهائيًّا.

**التحديث لاحقًا:** اضغط «تحقّق من التحديثات» في ترويسة البرنامج. لا
يتّصل بالإنترنت من تلقائه أبدًا — يسأل حين تطلب أنت فقط. والتحديث
تثبيتٌ فوق القديم: إعداداتك والنموذج المنزَّل يبقيان.

**اختياري:** تفعيل استخراج نص الشاشة (OCR) يحتاج Tesseract مثبَّتًا
منفصلًا — انظر [`INSTALL.md`](INSTALL.md).

## التشغيل من المصدر — للمطوّر

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows   —   source .venv/bin/activate على غيره
python -m pip install -r requirements.txt
python tools/doctor.py            # يتحقق من البيئة قبل التشغيل
python app.py
```

> **مهم:** الحزمة المطلوبة اسمها **`python-docx`** وليس `docx`. حزمة
> `docx` مشروع مهجور من زمن Python 2 ويسبب خطأ
> `No module named 'exceptions'` الغامض. التفاصيل والإصلاح في
> [`INSTALL.md`](INSTALL.md).

للتشغيل من سطر الأوامر دون واجهة:

```bash
python -m tools.run_pipeline --video "محاضرة.mp4" --output ~/VideoToDocOutput
python -m tools.run_pipeline --video "محاضرة.mp4" --rewrite --engine faster-whisper

# ملف صوتي بأي امتداد — مستند منسّق بلا لقطات
python -m tools.run_pipeline --audio "محاضرة.m4a"

# أعد بناء المستند من خطة محفوظة — ثوانٍ بدل ساعات
python -m tools.run_pipeline --rebuild ~/VideoToDocOutput/محاضرة

# جرّب الإعدادات على خمس دقائق قبل معالجة ثلاث ساعات
python -m tools.run_pipeline --video "محاضرة.mp4" --from 00:05 --to 00:10

# النص فقط: txt و md و srt و vtt بلا مستند
python -m tools.run_pipeline --video "محاضرة.mp4" --transcript-only

# مقرّر كامل، ملفًا تلو الآخر — فشل ملف لا يوقف البقية
python -m tools.run_pipeline --batch ~/محاضرات --denoise

# مصطلحات مادتك ترفع دقة أسماء الأعلام
python -m tools.run_pipeline --video "درس.mp4" --glossary "بوذا، اليوغا، Schoology"

# ادمج مهامّ منتهية في مستند واحد
python -m tools.run_pipeline --merge ~/out/جزء1 ~/out/جزء2 --merge-output ~/المقرر.docx

# صيغ إضافية بجوار المستند — أو none لتعطيلها كلّها
python -m tools.run_pipeline --video "درس.mp4" --export html,pdf,pptx,chapters

# حزمة تعليمية: أهداف ومسرد وأسئلة وبطاقات — بنموذج محلي مجاني
python -m tools.run_pipeline --video "درس.mp4" --study

# ترجمة ملفّات الترجمة إلى لغات أخرى
python -m tools.run_pipeline --video "درس.mp4" --translate en,fr
```

**فهرس المقرّر وتقرير التغطية** من مجلد الإخراج:

```bash
python -m tools.course_report ~/VideoToDocOutput --title "شبكات ٢٠١" --open
```

**مجلد وارد يُعالَج تلقائيًّا** — جهاز واحد يخدم القسم كلّه:

```bash
python -m tools.watch_folder --inbox "\\srv\محاضرات\وارد" --output D:\مخرجات --study
```

## المتطلبات

| المكوّن | ملاحظة |
|---|---|
| Python 3.10+ | |
| ffmpeg + ffprobe | يوضعان في `bin/` أو في `PATH`. **ffprobe إلزامي** — انظر ADR-013 |
| نموذج Whisper | يُنزَّل عند أول تشغيل بإذنك (`large-v3-turbo` ≈ 1.7GB) |
| ذاكرة | 8GB RAM كحد أدنى مع `large-v3` على المعالج |

بطاقة رسومات NVIDIA اختيارية؛ يُكتشف CUDA تلقائيًا ويُسقَط إلى المعالج
عند غيابه أو عند أي فشل — أثناء التحميل **أو** أثناء التنفيذ.

## قرارات معمارية جوهرية

**ADR-010 · المستند مدفوع بالنص لا بالصور.** كل مقطع منطوق يظهر **مرة
واحدة بالضبط**، والصور تُحقن عند طوابعها الزمنية. الضمانة مفروضة برمجيًا
في `document.planner.assert_lossless` وتُفحص في كل مستند ناتج.

**ADR-011 · عتبات كشف المشاهد تكيّفية.** لا رقم مطلق في الكود. العتبة
تُشتق من توزيع درجات كل فيديو (`median + k·MAD`) مع حدّ أدنى. عايِر على
مادتك:

```bash
python tools/calibrate_scenes.py محاضراتي/ --apply
```

الأداة تعرض توزيع الدرجات وعدد المشاهد عند قيم `k` مختلفة، وتوصي بقيمة
تقع في الهضبة المستقرة — النطاق الذي لا يتغيّر فيه العدد كثيرًا.

**ADR-012 · بلا PyTorch.** `faster-whisper` يعمل على CTranslate2. اكتشاف
CUDA وأنواع الحساب عبر `ctranslate2` مباشرة — يوفّر ~2.5GB ويزيل أكبر
مصدر لمشاكل التغليف.

**ADR-013 · ffmpeg و ffprobe مشحونان.** `imageio-ffmpeg` لا يشحن ffprobe
إطلاقًا؛ الاعتماد عليه يُفشل قراءة الميتاداتا من أول دالة.

**ADR-014 · لا تنزيل تلقائي للنموذج.** الاتصال الشبكي الوحيد يشترط إذنًا
صريحًا من المستخدم مرة واحدة.

**ADR-018 · كل مخرج تعليمي يُثبت مصدره أو يُسقَط.** مولّد الأسئلة
العام يكتب سؤالًا معقولًا عن موضوع المحاضرة سواءٌ قيل في التسجيل أم لا.
فكل عنصر هنا يحمل `segment_ids` من `transcription.json`، وتفحصها
`ai/study_verify` فعليًّا: سؤالٌ يستشهد بمقطع غير موجود، أو إجابةٌ خارج
خياراتها، أو مصطلحٌ لا يرد في النصّ ولا على الشاشة — كلّها تُسقَط
ويُسجَّل سببها.

**ADR-020 · الإعداد نيّة، والسجلّ شهادة.** `text_left_device` في سجلّ
التدقيق يُسجَّل عند **حدود الشبكة** داخل المزوّد — لا من الإعداد. رُصد
على مخرج حقيقي أن الإعداد كان `anthropic`، والمزوّد سقط قبل أن يُرسل
شيئًا، والسطر قال إن نصّ المحاضرة غادر الجهاز. وردٌّ بخطأ 401 يُعدّ
خروجًا (الطلب وصل)، وانقطاعُ اتصال لا يُعدّ.

**ADR-019 · السياسة تُطبَّق داخل `AppConfig.load` لا في المداخل.**
سياسةٌ تُطبَّق في الواجهة وسطر الأوامر ووضع الدفعات كلٌّ على حدة تبقى
صحيحة حتى يُضاف مدخلٌ رابع ينساها — وذلك المدخل هو الثغرة التي تُبطلها
كلّها. ولا يوجد طريق إلى `AppConfig` لا يمرّ بتلك الدالّة.

**ADR-015 · الدوران يُستنتج وقت التشغيل.** بعض بُنى OpenCV تطبّق مصفوفة
عرض الحاوية وبعضها يتجاهلها. افتراض أيّهما ينتج صورًا مقلوبة على نصف
الأجهزة، والـ XML يبقى سليمًا فلا يكشف العطل. القرار يُتَّخذ بمقارنة
الإطار بمرجع من FFmpeg (`utils/frames.resolve_rotation_plan`).

## الاستئناف

كل مرحلة تحفظ ناتجها بـ checksum في مجلد المهمة. إعادة التشغيل تتخطى
المراحل التي ما زال ناتجها صالحًا. حذف ناتج أو العبث به يُبطله ويُبطل كل
ما يليه تلقائيًا.

```
<output>/<اسم الفيديو>/
├── job_state.json      الحالة والمراحل المكتملة والـ checksums
├── metadata.json       عقد VideoMetadata
├── transcription.json  عقد TranscriptionResult
├── scenes.json         المشاهد ودرجات التغيّر
├── keyframes.json      الصور وبياناتها
├── plan.json           بنية الوثيقة + ثوابت سلامة النص
├── keyframes/          الصور المستخرجة
├── <اسم الفيديو>.docx  المخرج النهائي
├── <اسم الفيديو>.srt   ترجمة (اختيارية)
└── <اسم الفيديو>.vtt   ترجمة للويب (اختيارية)
```

**إعادة البناء بلا إعادة معالجة.** ما دام `plan.json` موجودًا، فتغيير
الخط أو الشعار أو حجم الصور أو إخفاء التوقيتات لا يستلزم إعادة التفريغ:
اضغط «أعد بناء المستند» في الواجهة، أو `--rebuild <مجلد المهمة>` في سطر
الأوامر. يستغرق ثوانٍ.

**ملفات الترجمة.** تُكتب تلقائيًا من توقيت الكلمات المحفوظ أصلًا في
`transcription.json`. لتعطيلها: `document.export_subtitles: false`.

## الاختبار والقبول

```bash
python -m pytest tests/ -q          # حزمة الاختبارات
python tools/run_acceptance.py      # كل بوابات القبول + تقرير JSON
```

`run_acceptance.py` يشغّل حزمة الاختبارات، ثم مصفوفة التوافق على كل ملفات
`testdata/corpus/`، ثم اثنتي عشرة بوابة جودة على كل مستند ناتج، ويصدر
`acceptance_report.json` بالنسب.

### قياس دقة التفريغ على مادتك

```bash
python tools/measure_wer.py --eval-set my_eval.json --model large-v3
```

حيث `my_eval.json` قائمة من `{"file": "...wav", "norm": "النص الصحيح"}`.
تُبلَّغ ثلاثة مقاييس معًا: WER الصارم، WER المتسامح إملائيًا، و CER.

## محرّكات التفريغ

النظام يدعم أكثر من محرّك خلف واجهة واحدة (ADR-017):

| المحرّك | PyTorch | الحالة |
|---|---|---|
| **faster-whisper** | لا | الافتراضي — خفيف وسريع، توقيت كلمات |
| Cohere Transcribe Arabic | نعم | اختياري — أدق على اللهجات، وزن مقيّد الوصول |

لتثبيت محرّك Cohere الاختياري — **بالمفسّر الصحيح** (أشهر سبب لفشل
التثبيت هو أن `pip` أصاب Python آخر غير الذي يشغّل التطبيق):

```bash
python tools/install_engine.py cohere
```

يكتشف كرت NVIDIA ويختار بناء PyTorch المناسب، ثم يتحقّق بنفس منطق
البرنامج. وعلى ويندوز يكفي النقر المزدوج على `تثبيت_محرك_Cohere.bat`.

لمعرفة سبب عدم جاهزية أي محرّك:

```bash
python tools/doctor.py
```

قِس بنفسك على مادتك:

```bash
python tools/benchmark_asr.py --eval-set my_eval.json
```

المقارنة الكاملة والمنهجية في [`docs/ASR_COMPARISON.md`](docs/ASR_COMPARISON.md).

## اختيار النموذج — أرقام مقاسة

قياس فعلي على FLEURS العربية (لهجة مصرية)، 86 ثانية كلام بشري بنصوص
مرجعية، على معالج بنواتين بصيغة `int8`:

| النموذج | دقة الكلمات | دقة الحروف | معامل الزمن | الحجم |
|---|---|---|---|---|
| **large-v3-turbo** (افتراضي) | **92.54%** | **98.64%** | **1.28×** | 1.7GB |
| large-v3 | 90.30% | 98.18% | 3.33× | 3.1GB |
| medium | 87.31% | 97.43% | 2.78× | 1.5GB |

النتيجة كانت مفاجئة: **turbo تفوّق على large-v3 في الدقة والسرعة معًا**
على العربية، ولهذا هو الافتراضي. لا تغيّر الترتيب دون إعادة القياس بـ
`tools/measure_wer.py`.

### كم تستغرق المعالجة؟

معامل الزمن يضرب في مدة الفيديو. لمحاضرة ساعة وثلث (81 دقيقة):

| النموذج | على المعالج | على كرت شاشة NVIDIA |
|---|---|---|
| large-v3-turbo | ~1 ساعة و45 دقيقة | ~13 دقيقة |
| large-v3 | ~4 ساعات و30 دقيقة | ~33 دقيقة |

الواجهة تعرض هذا التقدير **قبل** الضغط على «ابدأ»، وشريط التقدّم يعرض
الوقت المتبقي أثناء العمل.

## جودة المخرج — ما تغيّر ولماذا

فحص مخرج حقيقي (تسجيل شاشة 88 ثانية لنظام ويب) كشف ثلاث مشكلات:

| القياس | قبل | بعد |
|---|---|---|
| عدد الصور | 13 (**3 فارغة**) | 6 كلها ذات محتوى |
| حجم المستند | **8.50 MB** | **0.62 MB** |
| عدد الصفحات | صفحة لكل صورة | شكلان في الصفحة |

**١ · شاشات التحميل.** كاشف المشاهد يُطلق عند لحظة التغيّر، وهي بالضبط
لحظة بدء تحميل الصفحة. الحل: المنتقي يجرّب خمس لحظات داخل كل مشهد ويختار
اللحظة **المستقرة** — يقارن الإطار بإطار بعده وبحالة المشهد الأخيرة، ويعاقب
غير المستقر. مقياس كثافة الحواف يرفض الفارغ (قِيس: الفارغ 1.0–1.3٪ مقابل
المفيد 2٪ فأعلى).

**٢ · التكرار.** بصمة إدراكية (dHash) تُقارَن بكل الصور المحفوظة لا
بالسابقة فقط، فلا تتسرّب لقطات شبه متطابقة.

**٣ · الحجم.** JPEG بجودة 82 وعرض 1366 بدل PNG بعرض كامل. محاضرة ساعة
كانت ستنتج مستندًا يتجاوز 300 ميجابايت يتعذّر فتحه.

## القالب الاحترافي

المستند يُبنى بأنماط Word حقيقية لا بتنسيق يدوي، فيعمل الفهرس التلقائي

## جودة التفريغ — ما يقرّره مستوى الصوت

**تطبيع مستوى الصوت مُفعَّل افتراضيًّا**، وهذا أهمّ إعداد في البرنامج.

قياسٌ على تسجيل حقيقي مدّته 5:12: الصوت أهدأ بـ**15 dB** من الطبيعي
(وسيط ‎-36.5 dBFS)، و‏VAD ابتلع **75٪** من الكلام — بما فيه تسعون ثانية
متّصلة هي أكثر مناطق التسجيل نشاطًا. و`loudnorm` يرفع ذلك المقطع من
‎-36.0 إلى ‎-20.7 dBFS.

```yaml
application:
  normalize_audio: true    # الافتراضي — لا تُطفئه إلا لسبب
  denoise_audio: false      # اختياري: عدوانيّ على الأصوات الهادئة
```

والبرنامج يقيس مستوى مصدرك ويُسجّله، فإن كان هادئًا قال ذلك صراحةً —
لتعرف **لماذا** خرج تفريغك ناقصًا بدل أن تخمّن.

**ومصطلحات الشاشة تُمسح قبل التفريغ** وتُحقن في «مصطلحات المادة» إن
تركتها فارغة (`whisper.auto_screen_glossary`). الأثر مقيس: استرجاع أسماء
القوائم الإنجليزية من صفر من 12 إلى 8 من 12.

## خصوصية اللقطات

**قصّ زينة الشاشة مُفعَّل افتراضيًّا.** تسجيل الشاشة يلتقط مع المحتوى:
رابط النظام بمعرّفاته، وشريط مفضّلاتك، وشريط مهام ويندوز بتطبيقاتك
المفتوحة، وودجت الطقس باسم مدينتك — كلّها تدخل مستندًا يُوزَّع.

الكشف بنيويّ: الزينة صفوفٌ لا تتغيّر عبر الزمن، فتُقارن إطارات متباعدة
ويُقصّ الثابت من الأعلى والأسفل. ولا يُقصّ أكثر من ربع الارتفاع، ولا
يُقصّ شيء إن كان أكثر الإطار ثابتًا أصلًا — تسجيلٌ ساكن ليس شاشةً
مؤطَّرة، وقصُّه يحذف الدرس.

```yaml
frames:
  crop_screen_chrome: true   # الافتراضي
  crop_top_ratio: 0.0        # قصّ يدويّ بالنِّسب يُلغي الاستنتاج
  crop_bottom_ratio: 0.0
```

## الصيغ الإضافية — الحزمة التعليمية

المستند وحده لا يكفي صفًّا. `plan.json` عقدٌ مستقل عن صيغة الإخراج، فكل
صيغة هنا **مُصيِّرٌ** فوقه لا مسارٌ جديد في المعالجة:

| الصيغة | ما تفتحه | تحتاج |
|---|---|---|
| **html** | ملف واحد يُفتح على أي جهاز بلا تثبيت: بحث فوري في كل الكلام، فهرس جانبي، ونقرة على أي توقيت تقفز إليه في التسجيل. ويُطبع إلى PDF من المتصفّح بضغطة | — |
| **chapters** | قائمة فصول تُلصق في وصف الفيديو فيصير شريط التقدّم فهرسًا قابلًا للنقر | — |
| **pdf** | تحويل مستند Word نفسه، فيخرج مطابقًا له بالحرف | LibreOffice |
| **pptx** | شريحة لكل قسم بنقاطه، وشريحة لكل لقطة، والنصّ الكامل في ملاحظات المتحدّث | `python-pptx` |

الافتراضي `html` و`chapters` — وهما بلا أي اعتماد خارجي. للباقي:

```bash
pip install -r requirements-export.txt     # الشرائح
# وPDF ليس حزمة بايثون: https://www.libreoffice.org/download
python tools/doctor.py                     # يقول حالة الاثنين
```

**صفحة HTML مستقلّة تمامًا:** لا CDN ولا خط شبكي ولا سكربت مستورد —
الصور مضمّنة والأنماط داخل الملف. السبب عمليّ: المعلّم يرسلها بالبريد
أو يضعها على USB، ومرجعٌ خارجيّ واحد يكسرها على أول جهاز بلا إنترنت.
والتسجيل **لا يُنسخ ولا يُرفع**: زرٌّ يختار الملف من الجهاز فيربطه
بمشغّل الصفحة، وكل توقيت يصير نقطة قفز.

**والثمن صفر بعد أول معالجة.** الصيغ الأربع تُبنى من الخطة المحفوظة:

```bash
python -m tools.run_pipeline --rebuild ~/VideoToDocOutput/محاضرة
```

ثوانٍ، بلا تفريغ وبلا كشف مشاهد. من ملك `plan.json` ملك الصيغ كلّها.

**عقد الفشل:** هذه مخرجات إضافية لا شروط نجاح. مُصيِّر يسقط أو اعتمادٌ
يغيب يُسجَّل ويُتخطّى وحده، وتُكتب البقية، وتنجح المهمة. مستند Word
وحده هو ما يُفشل فشلُه المهمة.

## الحزمة التعليمية

مستند وصفحة وشرائح: كلّها تعرض ما قيل. والحزمة التعليمية تحوّله إلى
**مادّة يُمتحن بها** — أهداف تعلّم، ومسرد مصطلحات، وأسئلة تقييم، وبطاقات
مراجعة.

```bash
python -m tools.run_pipeline --video "درس.mp4" --study
```

| المخرج | الملف |
|---|---|
| دليل مذاكرة: أهداف وأسئلة ومسرد في صفحة واحدة | `<الاسم>.study.html` |
| بطاقات مراجعة يستوردها Anki ويفتحها Excel | `<الاسم>.flashcards.csv` |
| الحزمة الخام للتتبّع وإعادة البناء | `study.json` |

### ما يجعلها قابلة للاستعمال في صفّ

**كل سؤال يحمل مرجعه (ADR-018).** بجوار كل سؤال في دليل المذاكرة توقيتٌ
يقفز إلى المقطع الذي بُني منه. يضغطه المعلّم فيسمع الثانية نفسها ويحكم
في ثوانٍ بدل إعادة سماع المحاضرة.

**وما لا يُثبت مصدره يُسقَط.** طبقة التحقّق ترفض:

* سؤالًا يستشهد بمقطع غير موجود في التفريغ
* إجابة اختيارٍ من متعدد ليست **أحد خياراتها حرفيًا** — وهو سؤالٌ لا حلّ
  له، يظنّ الطالب الخطأ فيه خطأه
* سؤال اختيار بأقلّ من ثلاثة خيارات متمايزة
* إجابة «صح/خطأ» غير مفهومة
* مصطلحًا لا يرد في النصّ ولا على الشاشة — أشيع هلوسات المسرد

والمُسقَط يُعرض بعدده وأسبابه أسفل دليل المذاكرة. إخفاؤه يجعل حزمةً
نصفُها مرفوض تبدو حزمةً فقيرة، فيُلام المولّد بدل المحتوى.

**والمقارنة تتجاهل ما لا يراه القارئ:** همزة الألف، التاء المربوطة،
التشكيل، الترقيم. إسقاط سؤالٍ صحيح بسبب همزة خطأٌ بقدر قبول سؤال مخترع.

### المزوّد

| المزوّد | الخصوصية | التكلفة |
|---|---|---|
| **Ollama** (الافتراضي) | النص لا يغادر جهازك | مجاني |
| Claude API | ⚠ يُرسل نصّ التفريغ | مدفوع |
| خدمة بواجهة OpenAI | ⚠ يُرسل نصّ التفريغ | حسب الخدمة |

الافتراضي محلّي عمدًا: ميزةٌ يُفترض أن يجرّبها كل معلّم لا يصحّ أن تكون
تجربتها مشروطة بمفتاح مدفوع.

```bash
# تثبيت المزوّد المحلي مرّة واحدة
# https://ollama.com/download   ثم:
ollama pull qwen2.5:7b-instruct
```

**وبلا أي مزوّد تعمل الميزة جزئيًّا:** تخرج قائمة مصطلحات مشتقّة من نصّ
الشاشة (OCR) ومن التكرار — **بلا تعريفات، ولا ادّعاء بها**. وقيمتها
مقيسة: هذه القائمة نفسها تُلصق في خانة «مصطلحات المادة» فترفع دقّة تفريغ
المحاضرة التالية في المقرّر (انظر `video/screen_terms`).

**ولا يُستدعى النموذج مرّتين.** الحزمة تُحفظ في `study.json`، فـ
`--rebuild` يعيد تصيير الدليل والبطاقات منها في ثوانٍ بلا نداء واحد.

## النشر في مدرسة أو شركة

ثلاث حواجز تقف بين أداةٍ تعمل وأداةٍ **تُشترى**. اثنان منها مبنيّان هنا،
والثالث يحتاج مالًا لا كودًا.

### ١ · وحدة تعلّم لا ملفًّا يُرفع — SCORM 1.2

```bash
python -m tools.run_pipeline --video "درس.mp4" --study --export scorm
```

يخرج `<الاسم>.scorm.zip` تُرفع في **Moodle · Blackboard · Schoology ·
Canvas**، فتسجّل المنصّة من فتح الوحدة، ومن أتمّها، وبأي درجة في أسئلة
الحزمة التعليمية.

*ولماذا 1.2 لا 2004 ولا xAPI:* ‏1.2 هي الصيغة الوحيدة التي تقبلها
**كل** المنصّات الأربع بلا إعداد إضافي. و2004 أغنى ولا تدعمه منصّات
قائمة كثيرة، وxAPI يحتاج خادم LRS منفصلًا — أي بنيةً تحتية جديدة، وهي
بالضبط ما يجعل المدرسة تؤجّل القرار.

المحتوى كلّه داخل الحزمة بلا مرجع خارجي واحد: منصّات كثيرة تعمل خلف
جدار ناريّ يمنع الموارد الخارجية، وحزمةٌ تعتمد على CDN تخرج بيضاء عند
الطالب وحده.

### ٢ · إمكانية الوصول — WCAG 2.1 AA

كل صورة في المستند والصفحة والشرائح تحمل **نصًّا بديلًا حقيقيًّا**
(ADR‑بند 1.1.1). ومصدره الأوّل هو نصّ الشاشة المستخرَج بـ OCR — وهو
حرفيًّا ما يقرؤه المبصر في اللقطة.

هذا ليس تحسينًا اختياريًّا: جهاتٌ حكومية وجامعات تشترط الامتثال في
مشترياتها، ومستندٌ فيه ثلاثون لقطة بلا نصّ بديل يسقط في أول مراجعة —
وسقوطه سببُ استبعادٍ من قائمة المورّدين لا عيبٌ يُصلَح لاحقًا.

ولا نكتب نصًّا بديلًا مخترَعًا: «صورة توضيحية للمحتوى» جملةٌ تمرّ على
المدقّق الآلي وتخذل الأعمى. حين لا يوجد نصّ شاشة ولا تسمية، يُكتب موضع
اللقطة وتوقيتها — وهو صادق ومفيد.

### ٣ · سجلّ التدقيق — وحقلٌ واحد هو المهمّ

```bash
python -m tools.run_pipeline --video "درس.mp4" --audit
```

سطر JSONL لكل مهمّة في `~/.config/video_ai_doc/audit/audit.jsonl`
وفي مجلد المهمّة. وأهمّ حقوله:

```json
{"text_left_device": false, "cloud_providers": [], "status": "completed"}
```

سؤال كل مراجعة امتثال هو: هل غادرت بيانات المحاضرة هذا الجهاز؟ ولا يكفي
فيه قولُ «البرنامج محلّي» — لأنه **ليس محلّيًا بالكامل**: إعادة الصياغة
والحزمة التعليمية تُرسلان النصّ إلى مزوّد سحابي *إن اختار المستخدم
ذلك*. فالجواب يختلف من مهمّة إلى مهمّة، ولا يعرفه إلا السجلّ.

ويُكتب السطر مهما كانت النهاية — نجاحًا أو إلغاءً أو سقوطًا. سجلٌّ لا
يحوي إلا النجاحات لا يصلح للتدقيق أصلًا. **ولا يحوي السجلّ نصّ المحاضرة
إطلاقًا:** أسماء ملفّات وأزمنة وأرقام فقط.

### ٤ · سياسة الجهاز — للمسؤول لا للمستخدم

قسم تقنية المعلومات لا يعترض على أن البرنامج **يستطيع** الإرسال إلى
السحابة؛ يعترض على أن كل معلّم يستطيع تشغيل ذلك بمربّع اختيار.

انسخ [`packaging/policy.example.yaml`](packaging/policy.example.yaml)
إلى مكانٍ لا يملك المستخدم الكتابة فيه:

```
ويندوز:     C:\ProgramData\VideoToArabicWord\policy.yaml
لينكس/ماك:  /etc/videotoarabicword/policy.yaml
```

```yaml
allow_cloud_ai: false          # يمنع كل مزوّد يُخرج النصّ من الجهاز
require_audit_log: true        # يُلزم السجلّ ويمنع تعطيله
lock_export_formats: [html, chapters, scorm]
notice: 'مفروض بسياسة إدارة تقنية المعلومات'
```

الحقل المقفل يظهر في الواجهة **معطَّلًا مع سببه** لا مخفيًّا: المستخدم
الذي لا يجد الخيار يفتح بلاغًا، والذي يراه معطَّلًا يعرف أن جهة عمله
قرّرت ذلك.

**ولا تُشدَّد السياسة إلا نحو التقييد:** `allow_cloud_ai: true` لا
يُفعِّل شيئًا، يكتفي بعدم المنع. سياسةٌ تستطيع **تشغيل** إرسال البيانات
تصير طريق هجوم — ملفٌّ واحد يُدَسّ في مجلد مشترك يحوّل أداةً محلّية إلى
قناة تسريب.

### الحاجز الثالث: التوقيع الرقمي

المثبِّت غير موقَّع، فتظهر شاشة SmartScreen الزرقاء عند أول تشغيل. وهو
الحاجز الوحيد هنا الذي **لا يُحلّ بالكود**: يحتاج شهادة EV (‏≈ 300–600
دولار سنويًّا). أزِلها وتصير الحزمة قابلة للنشر المركزي بلا استثناءات
يدوية من قسم تقنية المعلومات.

## المقرّر كاملًا — لا محاضرة واحدة

### فهرس المقرّر وتقرير التغطية

```bash
python -m tools.course_report ~/VideoToDocOutput --title "شبكات ٢٠١"
```

المشكلة تظهر عند الملفّ العشرين لا الأول: عشرون مجلد مهمّة متشابه
الأسماء، وليس عند المعلّم وسيلة ليعرف أيّ محاضرة لم تكتمل، وأيّها بلا
حزمة تعليمية، وأيّها خرج بجودة قراءة منخفضة.

والبيانات كلّها موجودة ولا تُقرأ معًا: `job_state.json` يقول الحالة،
و`metadata.json` المدّة، و`plan.json` درجة القراءة، و`study.json` عدد
الأسئلة. التقرير يقرؤها جميعًا ويُخرج صفحة واحدة فيها صفٌّ لكل محاضرة
و**تقرير تغطية** يقول لكل نقصٍ **أمرَ الإصلاح** الذي يزيله:

```
ينقص 4: --export pptx
ينقص 3: --export scorm
ينقص 1: تابع المهمّة من «المهام السابقة…»
```

تقريرٌ يقول «ينقص كذا» بلا أن يقول كيف يُستدرَك يترك القارئ حيث وجده.

والتقرير **يقرأ ولا يغيّر شيئًا**: تقريرٌ يُصلح ما يجده من تلقاء نفسه
يصير خطِرًا — يكفي أن يُشغَّل على مجلد خاطئ.

### مجلد وارد يُعالَج تلقائيًّا

```bash
python -m tools.watch_folder --inbox "\\srv\محاضرات\وارد" --output D:\مخرجات --study
python -m tools.watch_folder --inbox ... --output ... --once   # لمهمّة مجدولة ليلية
```

**الرقم الذي يجعل هذا ضروريًّا:** ساعة فيديو تحتاج ساعة و45 دقيقة على
معالج، و13 دقيقة على كرت رسوميات. فنشرُ البرنامج على جهاز كل معلّم يعني
أن كلًّا منهم ينتظر ساعتين وحاسوبه محجوز — وهو ما يجعل الأداة تُجرَّب
مرّة ثم تُترك، مهما كانت جودة مخرجها.

والترتيب الصحيح مقلوب: **جهازٌ واحد بكرت رسوميات يعمل ليلًا.** يُسقط
المعلّم تسجيله في مجلد مشترك وينصرف، ويجد مخرجاته في الصباح. وتكلفة
الجهاز الواحد أقلّ من تعطيل عشرين حاسوبًا ساعتين.

**واستقرار الملفّ ليس تفصيلًا:** الملفّ الذي يُنسخ عبر الشبكة يظهر في
المجلد **فور بدء النسخ**. فلا يُقبَل حتى يثبت حجمه ووقت تعديله عبر
فحصين متتاليين — وإلا فُرِّغ نصف محاضرة.

**والسجلّ يمنع إعادة المعالجة:** الملفّ يُعرَّف بالاسم والحجم ووقت
التعديل، ويُسجَّل **الفاشل أيضًا ومعه سببه** — بلا ذلك يُعاد تفريغ ملفّ
تالف كل دورة إلى الأبد، وهو ما يحرق ليلة المعالجة كلّها. والسجلّ يُحفظ
بجوار الملفّات، فنقل المجلد ينقل معه سجلّه.

والخدمة تُحدِّث تقرير المقرّر بعد كل دورة، وتكتب سجلّ تدقيق دائمًا:
خدمةٌ تعمل بلا مشرف، والسجلّ هو الأثر الوحيد لما جرى ليلًا.

### الترجمة

```bash
python -m tools.run_pipeline --video "درس.mp4" --translate en,fr
```

يخرج `<الاسم>.en.srt` و`<الاسم>.en.vtt` — رمز اللغة في الاسم، فتعرض
المشغّلات «English» لا «Track 2». يستعمل مزوّد الحزمة التعليمية نفسه،
فلا إعداد ثانٍ ولا مفتاح ثانٍ.

**والتوقيتات لا تُمسّ.** البطاقات تُرقَّم ويُطلب نصٌّ مترجم لكل رقم، ثم
تُركَّب الترجمة على التوقيتات الأصلية. نموذجٌ يُعيد كتابة
`00:12:40 --> 00:12:44` سيخترع أرقامًا في مكانٍ ما من ملفٍّ فيه ألف
بطاقة، ولن يظهر الخطأ إلا عند الطالب الذي يشاهد.

**وعدد البطاقات ثابت:** النموذج يميل إلى دمج بطاقتين قصيرتين في جملة
أفصح — وهو تحسينٌ لغويّ **يُزيح الملفّ كلّه بعدها**. فإن عاد بعددٍ
مخالف تُرفض الدفعة وتبقى بطاقاتها بنصّها الأصلي: فجوةٌ في ملفّ ترجمة
تبدو عطبًا، وسطرٌ بالعربية يبدو — وهو كذلك — سطرًا لم يُترجَم.

## ملاحظة مهمة: محارف الاتجاه في Word

النسخة السابقة كانت تستخدم محارف العزل الاتجاهي (U+2066/U+2069) لمنع
انعكاس الأرقام. **تعمل في LibreOffice وتفشل في Microsoft Word**: يعرضها
Word مربّعات ظاهرة مكتوبًا داخلها `LRI` و `PDI`.

الحل الحالي بنيوي بلا أي محرف مضاف:

* قيمة لاتينية/رقمية خالصة ⇒ **فقرة LTR** (`w:bidi val=0`) بالمحاذاة
  المطلوبة، فيصح ترتيبها الداخلي
* نص مختلط ⇒ يُقسَّم إلى `runs`: العربية بـ `w:rtl` واللاتينية بدونه
* التواريخ ⇒ صيغة عربية طبيعية (`31 أغسطس 2026`) بدل ISO، لأن مجموعات
  الأرقام المفصولة بشرطات تنعكس بصريًا مهما ضُبط الاتجاه

اختبار انحدار يفشل إن عاد أي محرف تحكّم اتجاهي إلى المستند.
