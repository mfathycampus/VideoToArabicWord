# تنظيف تاريخ Git من تسجيلَي المحاضرة

**لم أنفّذ هذا نيابةً عنك عمدًا.** العملية تعيد كتابة تاريخ المستودع كلّه
وتحتاج دفعًا قسريًّا إلى GitHub باعتمادك أنت — وطرفية هذه الجلسة لا تملكه.
وخطوةٌ لا رجعة فيها يجب أن تُنفَّذ بيد صاحبها وهو يراها.

## ما المشكلة

الدفعة `f990928` أضافت ملفّين ثم حُذفا لاحقًا من الشجرة:

```
كيفية التعامل مع السبورة الذكية في المدارس الثانوية.mp4   45 MB
شرح كيفية عمل رابط اجتماع على التيمز.mp4                   22 MB
```

الحذف من الشجرة ليس حذفًا من التاريخ. الملفّان ما زالا داخل `.git`
(‏66 ميغابايت من أصل حجم المستودع)، ومدفوعان إلى `origin`. أي شخص
يستطيع استخراجهما بأمرٍ واحد:

```bash
git cat-file -p $(git rev-list --objects --all | grep "السبورة" | cut -d' ' -f1) > video.mp4
```

وسجلّ التغييرات يقول إن فيهما أصوات زملاء. هذا وحده يمنع جعل المستودع
عامًّا قبل التنظيف.

## التنفيذ

### ١ · نسخة احتياطية أولًا

```powershell
cd ..
git clone --mirror VideoToArabicWord VideoToArabicWord-backup.git
cd VideoToArabicWord
```

لا تتخطَّ هذه الخطوة. هي الشيء الوحيد الذي يعيد ما يُحذف.

### ٢ · الأداة

```powershell
python -m pip install --user git-filter-repo
```

### ٣ · الحذف

```powershell
python -m git_filter_repo --invert-paths `
  --path "كيفية التعامل مع السبورة الذكية في المدارس الثانوية.mp4" `
  --path "شرح كيفية عمل رابط اجتماع على التيمز.mp4" `
  --force
```

### ٤ · تحقّق قبل الدفع

```powershell
# يجب ألّا يظهر شيء
git rev-list --objects --all | Select-String "\.mp4"

# والحجم يجب أن ينزل من ~66MB إلى بضعة ميغابايت
git count-objects -vH
```

### ٥ · إعادة الرابط والدفع القسريّ

‏`git-filter-repo` يحذف `origin` عمدًا حتى لا يُدفَع شيء بالخطأ.

```powershell
git remote add origin https://github.com/mfathycampus/VideoToArabicWord.git
git push --force origin main
git push --force origin --tags
```

### ٦ · ما لا يكفيه الدفع

الدفع القسريّ لا يمسح ما خزّنه GitHub. بعده مباشرةً:

* احذف كل **Pull Request** قديم يشير إلى الدفعات المحذوفة (إن وُجد) —
  ‏GitHub يُبقي دفعات PR حيّةً بعد إعادة الكتابة.
* افتح تذكرة دعم لدى GitHub واطلب **garbage collection** على المستودع.
  بلا هذه الخطوة تبقى الدفعات القديمة قابلة للوصول بمعرّفها المباشر
  (‏`/commit/f990928`) رغم اختفائها من التاريخ.
* اعتبر التسجيلين **مكشوفَين** ما داما كانا على مستودع عامّ في أي وقت.
  إن كان المستودع خاصًّا طوال المدة فالخطر أقلّ بكثير.

### ٧ · بعد التنظيف

أي نسخة أخرى من المستودع على أي جهاز صارت تحمل التاريخ القديم. احذفها
واستنسخ من جديد بدل السحب — السحب سيعيد دمج ما حذفتَه.
